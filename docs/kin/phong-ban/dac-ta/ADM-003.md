## 4. Hợp đồng API

### 4a. `GET /api/cron/english-voa` — đổi hành vi phụ, không đổi vào/ra

| | |
|---|---|
| Quyền | `Authorization: Bearer CRON_SECRET` qua `checkCronAuth` (giữ nguyên; thiếu khoá → 503, sai khoá → 401) |
| Vào | không |
| Ra | như cũ: `{ added, errors[] }` hoặc `{ added: 0, message: "Chưa cấu hình ENGLISH_VOA_FEEDS" }` |
| **Mới** | Sau khi `cronAuth.ok`, **trước** mọi việc khác (kể cả nhánh thoát sớm "Chưa cấu hình ENGLISH_VOA_FEEDS"): `await recordCronRun("english-voa");` |

Mẫu đặt y hệt 4 cron kia (adm-code copy đúng):
```ts
import { recordCronRun } from "@/lib/adminOpsServer";          // thêm vào khối import, sau dòng 8
// …
  const cronAuth = checkCronAuth(process.env.CRON_SECRET, req.headers.get("authorization"));
  if (!cronAuth.ok) return NextResponse.json({ error: cronAuth.error }, { status: cronAuth.status });
  await recordCronRun("english-voa"); // QT-03: dấu "lần gọi gần nhất" cho trang Triển khai và hạn mức
  const feeds = (process.env.ENGLISH_VOA_FEEDS ?? "") …
```
Lý do vị trí: (1) **sau** khoá — gọi sai khoá không được tính là "đã gọi" (bài `t-admin-ops.ts:31-34` đã khẳng định điều này cho remind-exam); (2) **trước** nhánh `feeds.length === 0` — màn Triển khai định nghĩa dấu này là "lần được gọi, chưa phải bằng chứng chạy xong" (`trien-khai/page.tsx:81`), nên chưa cấu hình nguồn vẫn là một lần gọi hợp lệ; (3) `await`, **không** bọc try — `recordCronRun` tự nuốt lỗi (`adminOpsServer.ts:15-20`), bọc thêm là thừa và lệch 4 route chị em. Chuỗi `"english-voa"` phải **bằng đúng** `key` trong `CRON_JOBS` và tên thư mục route — ba chỗ một tên (test 8a kiểm).

### 4b. `GET /api/admin/trien-khai` — không đổi hợp đồng, mảng dài thêm 1

| | |
|---|---|
| Quyền | `MANAGE_REVENUE` (giữ) |
| Ra | `crons: CronView[]` có thêm `{ key: "english-voa", label, schedule: "Mỗi ngày 06:30 giờ VN", lastText, status, tone }`; thứ tự = thứ tự `CRON_JOBS` (đặt cuối) |

Phần tử mới trong `CRON_JOBS` (`adminOps.ts`, sau dòng 57):
```ts
  { key: "english-voa", label: "Lấy bài VOA Learning English", path: "/api/cron/english-voa", schedule: "Mỗi ngày 06:30 giờ VN", maxGapHours: 36 },
```
Đổi giờ: `30 23 * * *` UTC → 23:30 + 7h = **06:30 giờ VN** (khớp `docs/tieng-anh/DAC-TA.md:103`). `maxGapHours: 36` như 4 dòng kia (ngày không gọi là "chậm", dung sai 12h cho Vercel lệch). Chú thích dòng 52 đổi thành: `/** Khớp vercel.json: cả năm chạy mỗi ngày (23:30, 0:00, 0:30 và 1:00 UTC). Quá maxGapHours mà chưa thấy gọi thì báo "chậm". */`.
