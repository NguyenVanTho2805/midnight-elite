## Khi build production đỏ vì cảnh báo mất dữ liệu (cách làm bằng tay)
Dùng khi log build của Vercel có dòng `There might be data loss when applying the changes` và script **không tự** xử lý được (tức là có cảnh báo KHÁC "thêm ràng buộc duy nhất"). Bản đang chạy vẫn an toàn trong lúc build đỏ.
1. **Đọc cảnh báo trước.** Vercel → dự án `midnight-elite` → Deployments → bản đỏ → Build Logs → tìm các dòng bắt đầu bằng `•`. Nếu có `You are about to drop…` / `will be cast from…` / `table, which is not empty` thì đó là **mất dữ liệu thật**: dừng, chụp lại log, hỏi người làm kỹ thuật, sao lưu (Neon: tạo nhánh từ DB production) rồi mới tiếp. Chỉ khi mọi dòng là thêm ràng buộc / thêm cột / thêm bảng thì sang bước 2.
2. **Bật cờ tạm.** Settings → Environment Variables → `PRISMA_ACCEPT_DATA_LOSS` (Production) → Edit → giá trị `1` → Save.
3. **Dựng lại.** Deployments → bản đỏ → nút `⋯` → Redeploy → chờ READY. Mở Build Logs, tìm dòng `Your database is now in sync with your Prisma schema`.
4. **Gỡ cờ ngay**, kể cả khi bản dựng lại vẫn lỗi: quay lại Environment Variables, đặt `PRISMA_ACCEPT_DATA_LOSS` về `0`. Cờ để `1` thì mọi lần build sau đều được phép xoá cột/bảng mà không cảnh báo.
